# README 图文使用说明设计

## 目标

为当前 Vue 3 / Spring Boot 版本提供准确、易浏览的中文使用文档。根 README 保持简洁，帮助读者快速了解、启动并找到对应角色的操作入口；详细步骤集中在独立用户指南中。

## 文档结构

### 根 README

- 项目简介、主要能力、技术栈和角色权限。
- Docker 一键启动与本地开发步骤。
- 默认访问地址和演示账号。
- 当前界面预览。
- 学生、教师、管理员操作指南的锚点链接。
- 项目结构、测试和贡献说明。

删除或改正已经失效的旧目录、命令、端口和重复章节，避免新旧教程同时存在。

### `doc/user-guide.md`

- 开始使用：访问系统、登录、退出及角色权限。
- 学生流程：进入考场、参加考试、提交答卷、查看成绩与答题详情。
- 教师流程：维护题库、创建和管理试卷、查看成绩及学情。
- 管理员流程：教师全部能力，以及学科和用户管理。
- 常见问题：页面入口不可见、数据库初始化、端口和数据持久化。

每个流程采用“操作步骤 + 对应截图 + 结果说明”的固定结构。截图仅展示说明当前步骤所需的界面。

## 图片规范

- 图片存放在 `doc/images/guide/`，使用英文小写短横线命名。
- 从当前运行版本重新截取，不复用旧版界面图片。
- 桌面端截图使用统一视口和比例；登录页及三个角色各保留有代表性的界面。
- 不展示真实个人信息、令牌、数据库密码或其他敏感内容。
- 图片使用相对路径，提供有意义的替代文本和简短图注。

## 验证

- 使用 Docker Compose 构建并启动应用。
- 分别以 `student`、`teacher`、`admin` 登录，按指南走通代表性流程并采集截图。
- 检查 README 和用户指南中的相对链接、图片路径及 Markdown 基本格式。
- 对照实际脚本、配置和页面确认命令、端口、菜单名称及角色权限。

## 范围限制

- 不修改应用功能或界面。
- 不把完整 API 文档或部署运维手册并入本次用户指南。
- 不为每一次点击堆叠截图；优先展示能说明关键状态的页面。
